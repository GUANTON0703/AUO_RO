# 裝備 / 卡片 / 掉落擴充計畫（P1~P6）

方案 C：戰力做成打寶目標，不白送。強卡低掉率、關鍵帶洞武器只有 boss / 深區怪掉，
配一次輕度怪物 HP 調整（關鍵區 +20~40%，用 gen 條目 `hp_mult`）。
裝備數值照原版 RO、攻速 193 = 3 擊（P0 已做）。

## 現況

- 裝備 52 件：武器 21、鎧甲 6、鞋 5、披肩 6、頭飾 6、飾品 5、盾 3
- 卡片 104 張，效果已支援：flat_stat / percent_stat / element_resist / race_damage /
  size_damage（P0 新增）/ weapon_element / on_hit_proc（不套用）
- 40+ 張地圖，怪物用 `data/monsters.src.json` + `build_monsters.py` 產生

## 通用規則

- **帶洞高階武器**：只從 boss / 深區精英怪掉，掉率 0.5~2%
- **關鍵卡**：掉率 0.05~0.3%（越關鍵越低）
- **一般帶洞裝**：中階怪掉率 1~3%，或 NPC 買得到 [0] 版、帶洞版靠掉
- 新怪一律 `gen: true`，drops 寫進條目
- 每批跑 `build_monsters.py` + `check_content.py` + 相關測試 + Codex

## 引擎待擴充（P6 會撞到，不擋 P1~P5）

1. `race_damage` 支援負值（減傷卡：塔拉蛙、Thara Frog）
2. 「對 Boss +X%」判定（深淵騎士卡、首領之劍）— 需要 combatant 帶 `is_boss`
3. Ice Pick 型武器（傷害隨目標 DEF）
4. 完全迴避 / perfect dodge（Yoyo、Morrigane 套）— 目前 flee 是線性,完全迴避是獨立骰

## 批次順序與驗收

每批：改 monsters.src.json + equipment.json + cards.json →
`build_monsters.py` → `check_content.py` → 跑 combat/settlement/content 測試 →
加 2~3 個測試（新卡效果、新怪掉落、hp_mult）→ Codex → commit → 部署。

P7：各職畢業路線驗證——寫一支模擬腳本，每個 build 用「該區掉落能湊到的裝」跑同級怪，
確認 clear 時間落在合理帶（不會太快 = 難度守住，也不會打不動）。
