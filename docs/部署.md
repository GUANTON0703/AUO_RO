# ROtxt 部署 Runbook

單一 Docker image（uvicorn 跑 FastAPI），跑在 J1900（`10.0.4.33`），SQLite 檔在 bind mount，
經 Nginx Proxy Manager 反向代理對外走 HTTPS，DB 每天 04:30 備份、保留 14 天。

本機沒有 docker，**image 在 J1900 上 build**。本機只負責改碼、跑測試、把原始碼推上去。

---

## 1. 首次部署

### 1.1 J1900 準備目錄

```sh
ssh root@10.0.4.33
mkdir -p /srv/rotxt/{data,backups,src}
```

### 1.2 本機把原始碼推上去

```sh
# 在 H:\創業\ROtxt\ 下
rsync -av --delete \
  --exclude .venv --exclude .git --exclude '*.db' --exclude '*.db-*' \
  --exclude .pytest_cache --exclude __pycache__ \
  ./ root@10.0.4.33:/srv/rotxt/src/
```

（`.dockerignore` 已排除 tests/client/scripts/docs/db，build 時不會進 image；rsync 這裡多推一點沒差。）

### 1.3 J1900 build image

```sh
cd /srv/rotxt/src
docker build -t rotxt:latest .
```

### 1.4 設定檔

```sh
cp /srv/rotxt/src/deploy/rotxt.env.example /srv/rotxt/rotxt.env
vi /srv/rotxt/rotxt.env          # 按需調整；正式版 STAT/SKILL_RESET_FREE 維持 false
chmod 600 /srv/rotxt/rotxt.env

cp /srv/rotxt/src/compose.yaml /srv/rotxt/compose.yaml
cp /srv/rotxt/src/deploy/backup.sh /srv/rotxt/backup.sh
chmod +x /srv/rotxt/backup.sh
```

### 1.5 起容器

```sh
cd /srv/rotxt
docker compose up -d
curl -s localhost:8010/health      # {"status":"ok"}
```

`/data` 權限：容器內是 uid 1000，若掛載目錄不是它的：

```sh
chown -R 1000:1000 /srv/rotxt/data
```

### 1.6 產首批邀請碼

```sh
docker exec rotxt python -m server.admin invite --count 10
```

印出的碼記進 vault `記憶\帳號與服務.md`。

### 1.7 NPM 反向代理

NPM 管理介面 `http://10.0.4.33:81` → Proxy Hosts → Add：

- Domain Names：`rotxt.<你的網域>`（子網域用哪個由你定，可另開 A record 或走 duckdns）
- Scheme：`http`，Forward Host：`127.0.0.1`，Forward Port：`8010`
  （若 NPM 跑在 docker 且無法連 host loopback，改用容器名 `rotxt` + port `8000`，並把兩個容器接同一個 docker network）
- Block Common Exploits：開
- SSL 分頁：Request a new SSL Certificate、Force SSL、HTTP/2、開 Websockets Support（未來 WebSocket 用）

驗證：`curl -s https://rotxt.<網域>/health`

### 1.8 裝備份 timer

```sh
cp /srv/rotxt/src/deploy/rotxt-backup.service /etc/systemd/system/
cp /srv/rotxt/src/deploy/rotxt-backup.timer   /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now rotxt-backup.timer
systemctl list-timers rotxt-backup            # 確認下次觸發時間
```

不想用 systemd 就加 crontab：`30 4 * * * /srv/rotxt/backup.sh`

### 1.9 朋友端連線

給對方 repo（或打包的 `client/` + `pyproject.toml`）：

```sh
uv sync
uv run python -m client --server https://rotxt.<網域>
```

## 2. 更新版本

```sh
# 本機
rsync -av --delete --exclude .venv --exclude .git --exclude '*.db' --exclude '*.db-*' \
  --exclude .pytest_cache --exclude __pycache__ \
  ./ root@10.0.4.33:/srv/rotxt/src/

# J1900
cd /srv/rotxt/src && docker build -t rotxt:latest .
cd /srv/rotxt && docker compose up -d      # 用新 image 重建容器
docker image prune -f
curl -s localhost:8010/health
```

---

## 3. 回滾

build 前先留舊 image：

```sh
docker tag rotxt:latest rotxt:prev      # 更新前先打標籤
```

要回滾：

```sh
docker tag rotxt:prev rotxt:latest
cd /srv/rotxt && docker compose up -d
```

或直接在 `/srv/rotxt/src` 上 `git checkout <舊 commit>` 重 build。

---

## 4. 改資料 / schema

- `data/*.json` 是打進 image 的，改內容要重 build（走 §2）。
- schema 目前是 `CREATE TABLE IF NOT EXISTS`，**加欄位不會自動生效**。開發期都砍 db 重建，
  正式上線後不能這樣——加欄位要手動 `ALTER TABLE` 或寫 migration。這是 v1.1 必做項。

---

## 5. 常見問題

- 容器起不來：`docker logs rotxt`
- NPM 502：確認 `docker compose ps` 容器 healthy、`ports` 綁對、NPM forward 的 host/port 對
- `/data` 權限：`chown -R 1000:1000 /srv/rotxt/data`
- 備份沒跑：`systemctl status rotxt-backup.timer`、手動 `journalctl -u rotxt-backup`

---

## 6. 機密處理

- `rotxt.env` `chmod 600`、**不進 git**（repo 只有 `deploy/rotxt.env.example`）。
- 邀請碼是唯一的發放機制，產了就記進 vault `記憶\帳號與服務.md`。
- 無外部 API 金鑰。
