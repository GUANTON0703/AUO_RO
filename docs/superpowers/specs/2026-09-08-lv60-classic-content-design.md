# Lv1–60 經典內容補全設計

## 目標

在不改變文字版 RO 的回合制、掛機與現有職業系統前提下，補足 Lv1–60 的經典 Pre-Renewal 練功、掉落與裝備選擇；名稱、地區與怪物出處盡量依經典設定，數值則依現有角色成長與安全撤退機制校準。

## 邊界

- 基準：二轉前／二轉期的 Pre-Renewal 內容，Base Level 上限維持 60。
- 不含三轉、轉生、PvP、組隊副本、寵物與 Lv61+ 地區。
- 不直接照搬原版數值、掉率或 NPC 售價；避免破壞目前的 Zeny、精煉與單人掛機平衡。
- 每隻新增怪物都有出沒地圖、材料掉落與一張可插入的卡片；資料統一由 `monsters.src.json` 與 `build_monsters.py` 生成。

## 三批交付

### 第一批：地圖、怪物與卡片

以現有 36 張地圖、133 隻怪、85 張卡為基線，補齊 Lv1–60 常見的經典練功區與替代路線。優先順序為沉沒之船、斯芬克斯深層、獸人地城深層，以及現有區域缺少的怪物群。每個地區獨立提交，加入前以同級角色模擬確認能打贏、也不會成為唯一最優解。

### 第二批：NPC 商店與初中期裝備

把目前全域單一商店改為符合文字版玩法的「品類商店」清單：補品、移動用品、遠距職業彈藥／消耗品、精煉材料與 Lv1–60 的白裝。購買與賣出維持現有 API；若某原版商品需要目前沒有的戰鬥系統，先不納入販售。

### 第三批：卡片效果覆蓋

逐一盤點新增卡片的效果。現有引擎已能處理固定屬性、百分比屬性、武器屬性、種族增傷、屬性抗性與命中 proc；超出這些能力的卡片分成「需要引擎功能」與「暫不收錄」，不以只有文字描述的無效卡片充數。

## 資料與驗證

- 使用 rAthena 的 Pre-Renewal 資料庫作為可版本化的怪物／物品參考，並保留本專案既有繁中命名。
- 對每個新增區域新增內容載入測試，以及代表性掉落／卡片插槽測試。
- 針對每個等級帶（1–9、10–19…55–60）維持至少兩個可選掛機地圖，避免單一路線。
- 每批完成後跑完整 pytest、審核差異、部署並做線上 health/content smoke check。

## 成功條件

1. Lv1–60 每十級都有至少兩條可行練功路線，且地圖／怪物以經典 RO 區域為主。
2. 新增怪物皆有材料、Zeny 與卡片價值；新增卡片不含無效效果。
3. 商店不販售無法使用的職業道具。
4. 現有角色、背包與已部署資料庫可無 migration 破壞地繼續使用。
