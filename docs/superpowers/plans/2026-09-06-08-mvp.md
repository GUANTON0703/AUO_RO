> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。
> **審核政策**：不跑 codex。分批做完跑 `uv run pytest -q` + 掃 diff；階段收尾一次自行審核。

**Goal:** MVP 王的冷卻挑戰制——每隻 MVP 個人冷卻好了可以發起挑戰，逐回合王戰，贏拿豐厚掉落 + 經驗，輸扣少量經驗，可中途逃（王重置、短冷卻、不扣經驗）。

**Architecture:** `character_mvp_cooldowns` 表記每隻 MVP 的下次可挑戰時間。`server/mvp/` 純函式做「挑戰結算」（玩家 Combatant + MVP + 設定 → 結果 + 逐回合事件）。API 兩個端點：列 MVP + 冷卻、發起挑戰。客戶端加 `mvp` 選單。

**Tech Stack:** 沿用。

## 設計決策

1. **冷卻**：每隻 MVP 的 `cooldown_hours` 已在 `data/mvps.json`（8~24h）。挑戰後（不論輸贏）設 `available_at = now + cooldown_hours`。**中途逃**只進 1 小時短冷卻。
2. **中途逃**：`simulate_fight` 加 `flee_hp_frac` 參數——每回合開始時若「第一位」（玩家）HP < `max_hp * flee_hp_frac` 就停，`outcome="fled"`。挑戰預設 `flee_hp_frac=0.15`，body 可傳 0 關閉（硬拚）。
3. **輸贏獎懲**：
   - 贏：MVP 的 `drops` 全部按機率擲一次入袋（MVP 卡 drop_rate 已較高 ~0.03，這裡再乘 3 當「挑戰加成」）+ `base_exp`/`job_exp`（MVP 的，已是雜怪 ~9 倍）+ Zeny（`zeny_per_kill(mvp) * 5`）。
   - 輸：扣當前等級 **1.5%** 的 base_exp（`round(base_exp_for_next(level) * 0.015)`，不會使等級倒退——扣到 0 為止）。
   - 逃：無獎無懲。
4. **MVP 數值重調**：目前 `data/mvps.json` 的 boss 用 `baseline(level, "boss")`（HP ×12），太肉（Lv48 王 36883 HP）。**本階段重新產一次 MVP 數值**，boss HP 倍率降到 ×6、ATK ×1.7，目標：養好的同級玩家能在 30~80 回合打贏、會痛但不被秒。改 `monster_stats.py` 的 boss 係數 + 重寫 `data/mvps.json` 的 stats 區塊。
5. **挑戰用玩家「當前掛機血量」還是「滿血」**：滿血。挑戰是獨立事件，進場滿血滿魔。不影響掛機狀態（掛機中也能挑戰，掛機 hunt_hp 不動）。
6. **一帳號一角色**（跟前面一致，操作第一隻）。

    ```python
    @dataclass
    class ChallengeConfig:
        flee_hp_frac: float = 0.15
        loss_exp_penalty_frac: float = 0.015
        mvp_drop_multiplier: float = 3.0
        win_zeny_multiplier: int = 5

    @dataclass
    class ChallengeResult:
        outcome: str          # win / loss / fled
        rounds: int
        base_exp: int
        job_exp: int
        zeny: int
        exp_penalty: int
        drops: dict
        events: list          # simulate_fight 的 events（asdict 之後）+ 一個結果事件
    ```

    1. `foe = Combatant.from_monster(mvp)`
    2. `fight = simulate_fight(player, foe, rng, max_rounds=400, flee_hp_frac=cfg.flee_hp_frac)`
    3. `outcome` = "win" if `fight.winner == player.name` else "fled" if `fight.outcome == "fled"` else "loss"

## Task 4: MVP API

**Files:** Create `server/api/mvp.py`; Modify `server/app.py`; Test `tests/test_api_mvp.py`

- `GET /api/mvp` → `[{id, name, level, home_map_id, home_map_name, available, seconds_remaining, cooldown_hours}]`
- `POST /api/mvp/challenge` body `{mvp_id, flee_hp_frac?}` →
  - 驗 `mvp_id` 存在、冷卻 `is_available`
  - `build_player_combatant`（滿血）
  - `challenge_mvp(...)`
  - win → `inventory.apply_drops` + `apply_base_exp`/`apply_job_exp` + `apply_progression`（zeny）
  - loss → base_exp 扣 `exp_penalty`（`apply_progression` 用負的 exp delta，或 repo 加 `deduct_base_exp`，不使等級倒退）
  - 任何結果 → `mvp.set_cooldown(char, mvp_id, hours = mvp.cooldown_hours if outcome != "fled" else 1)`
  - 回 `{outcome, rounds, base_exp, job_exp, zeny, exp_penalty, drops, events, character:{...}}`
