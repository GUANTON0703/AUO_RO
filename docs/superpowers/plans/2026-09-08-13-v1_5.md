## 決策（使用者 2026-09-08 拍板）

1. **三轉分兩段**：這批（第 3 波）只補齊二轉技能；三轉職業樹本身當第 3 波，Base 上限拉 99、補高等地圖怪。
2. **技能樹**：我照經典 RO 設計前置圖（點 A 到 N 級才能點 B）。手機 UI 用縮排清單 + 鎖頭，不做連線樹狀圖。
3. **Boss 挑戰**：戲劇化重播單場戰鬥。按挑戰 → 結束當前掛機 → 進 Boss 戰狀態 → 逐行播放（20~40 秒）→ 顯示勝負與獎勵 → 回待命。**獎勵在挑戰當下就結算入袋、存事件，畫面只是重播**（中途關頁不影響）。
4. **屬性相剋**：含武器屬性系統。附魔卡片（鑲上去改武器屬性）+ 少量屬性武器都做。魔法本來就有屬性。
5. **proc 技能**：二段攻擊（double_attack）、偷竊（steal）、致命毒擊（envenom 中毒 DoT）三個。資料結構已就緒，只差引擎。
6. **圖鑑收集加成**：第 2 波做。每擊殺一種怪記一筆、每張卡拿過記一筆，達門檻給小幅全域加成。

### （原規劃）第 1 波：引擎核心（我主做 + 1 個子代理產技能資料）

**目標**：屬性相剋、武器屬性、附魔卡、卡片 element_resist / race_damage 生效、proc 三技、二轉技能資料補齊、技能前置條件機制。做完角色能靠屬性剋制與二轉技能打更深。

### Task 0 — Migration 機制
- `schema.sql` 加 `schema_migrations(version INTEGER PRIMARY KEY, applied_at TEXT)`。
- `db/connection.py`：`_MIGRATIONS: list[tuple[int, Callable[[Connection], None]]]`。`init_db()` 跑完 `schema.sql`（CREATE IF NOT EXISTS）後，依序套用 version 大於已記錄的 migration，每個包一交易、記進 `schema_migrations`。
- 把現有 `init_db()` 裡那串手寫 `ALTER TABLE`（role、hunt_* 欄、equipped_slot='accessory1' 併轉、hunt_loot='{}' reset）整理成 migration 1。
- 之後所有 schema 變更走 migration，不再手寫進 init_db。

### Task 1 — schema 欄位
- `EquipmentDef.element: str = "neutral"`（武器用；防具留 neutral）。
- `SkillDef.requires: dict[str, int] = {}`（skill_id → 需要的等級）。
- `CardDef` 不動（effects 已支援 element_resist / race_damage / on_hit_proc）。
- `content/__init__.py` 驗證：`equipment.element` 在 Element enum；`skill.requires` 的 key 存在且屬同職或前職。

### Task 2 — Combatant 加欄位
- `attack_element: str = "neutral"`（玩家取武器屬性；附魔卡 / endow 覆蓋）。
- `element_resist: dict[str, int]`（element → 減傷 %，來自卡片）。
- `race_bonus: dict[str, int]`（race → 加傷 %，來自卡片）。
- `element: str` / `race: str`（受擊方判定用；`from_monster` 帶怪物自己的）。

### Task 3 — build_player_combatant 聚合
- 讀已裝武器的 `element` → `attack_element`。
- 掃所有已鑲卡片：`element_resist` 累加進 `element_resist` dict；`race_damage` 累加進 `race_bonus` dict。
- 附魔卡：鑲在武器上的 element 類卡片 → 覆蓋 `attack_element`（優先於武器本身屬性）。

### Task 4 — 傷害公式接相剋
- `formulas.physical_damage` / `magic_damage` 已有 `element_multiplier` 參數，加 `resist_pct: int = 0`。
- 戰鬥引擎 `_auto_attack` / `_physical_skill` / `_magic_skill`：
  - 攻擊屬性 = skill 的 element（有的話）否則 attacker.attack_element。
  - `mult = element_chart.multiplier(attack_element, defender.element)`。
  - `resist = defender.element_resist.get(attack_element, 0)`。
  - `race = attacker.race_bonus.get(defender.race, 0)`。
  - 傷害 = `base * mult * (1 + race/100) * (1 - resist/100)`。
- `element_chart.json` 已建，`ElementChart.multiplier` 已在。

### Task 5 — proc 三技
- `_auto_attack`：命中後，若 attacker 有 `double_attack` 被動（learned），依 `chance_pct[level]` roll，中了再打一擊（記一個 attack 事件標「連擊」）。
- `steal`（active）：`cast_skill` 收到 `proc / steal_loot` → 對該場戰鬥標記「本場額外撈」，settlement 這隻怪死掉時多給一點 zeny（`zeny_per_kill * 0.3` 之類，記進抽象清單）。
- `envenom`（`physical_hit` + `debuff: "poison"`）：命中後套一個 poison DoT status（用現有 `Status(kind="dot", ...)`，`tick_statuses` 已會扣血）。DoT 傷害 = 目標 max_hp 的小比例 or 固定值 × level。
- 戰鬥事件：連擊 / 中毒 各記一行（給網頁掛機紀錄顯示）。

## 子代理規格 6（二轉技能資料）

> 交給 `model: sonnet`。產出兩個檔案的 diff，不改程式。

**產出**：`data/skills.json` 新增 ~50 條、`data/jobs.json` 6 個二轉職業的 `skill_ids` 填上。

**每個職業挑 8~10 個經典二轉技能**，效果只能用這些型別（照 `data/skills.json` 現有格式）：
- `physical_hit`：`{type, element?, power_pct:[5個], hits?:[5個], debuff?:"poison"}`
- `aoe`：同上（多打群體，數值當單體算）
- `magic_hit`：`{type, element, power_pct:[5], hits?:[5]}`
- `heal_hp`：`{type, flat?:[5] | matk_pct?:[5]}`
- `buff`：`{type, stats:{stat:[5], ...}, duration_s}`（作用施法者）
- `debuff`：`{type, stat, pct:[5], duration_s}`（作用目標）
- `passive_stat`：`{type, stat, amount:[5]}`
- `proc`：`{type, event:"on_attack", chance_pct:[5], effect:"extra_hit"}`

**每條技能欄位**：`id`(snake_case)、`name`(繁中)、`job_id`、`kind`(active/passive)、`max_level`(5 或 10)、`sp_cost`([max_level 個]，passive 全 0)、`cooldown_s`、`effects`、`idle_default`(`{enabled, trigger, priority}`；trigger ∈ every_turn/cooldown_ready/sp_available/hp_below_50/hp_below_30/passive)、**`requires`**(`{}` 或 `{"skill_id": 等級}`——前職或同職技能)。

**職業對照（照經典 RO，砍到可實作）**：
- knight：騎士精神(passive atk)、猛擊(bowling_bash 物理)、拋擲長矛(spear_boomerang 物理遠)、二刀連擊(twohand_quicken buff aspd)、盾牌反擊(counter buff)、長矛精通(passive)、氣絕劍(brandish 物理大)…前置多半 `bash` / `magnum_break`。
- wizard：暴風雪(storm_gust 水 aoe)、地獄烈焰(meteor fire aoe)、雷霆(jupitel_thunder wind)、水球(water_ball 水)、寒冰盾(frost buff mdef)、放大魔力(amplify buff matk)…前置 `fire_bolt`/`cold_bolt`/`lightning_bolt`。
- hunter：野獸剋星(passive vs brute)、鷹眼連擊(blitz proc extra_hit)、鋼鐵烏鴉(steel_crow passive atk)、charge arrow(擊退物理)、sharp shooting(爆擊物理)、順風(wind_walk buff agi/flee)…前置 `double_strafe` 等。
- priest：主禱文(magnificat buff sp regen)、聖光彈(holy_light holy magic)、天使之護(kyrie buff)、破咒(lex_divina debuff)、驅逐惡魔(turn_undead holy vs undead)、判決(magnus 大範圍 holy)、增益禱告(gloria buff luk)…前置 `heal`/`blessing`。
- blacksmith：腎上腺素(adrenaline buff aspd)、極限精神(power_thrust buff atk)、狂暴(over_thrust buff atk 大)、鎚擊(hammer_fall debuff stun)、武器完美(weapon_perfection passive)、金剛(skin_temper passive def)…前置 `mammonite`/`cart_revolution`。
- assassin：音速衝擊(sonic_blow 多段物理)、毒粉(venom_dust debuff)、毒液噴濺(venom_splasher poison aoe+dot)、附毒(enchant_poison buff 讓攻擊帶毒)、匕首精通(passive)、隱匿(cloaking buff flee)、左右手練習(passive atk)…前置 `envenom`/`double_attack`。

不確定的技能寧可少放、選穩的。做完自己核對：所有 `requires` 的 key 都存在、`job_id` 對、`sp_cost` 長度 = `max_level`。
