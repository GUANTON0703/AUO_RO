# 部署 Implementation Plan

> **For agentic workers:** superpowers:subagent-driven-development。
> **審核政策**：不跑 codex。分批做完跑 `uv run pytest -q` + 掃 diff；階段收尾一次自行審核。

**Goal:** 把伺服器打包成容器、跑在 J1900、經 NPM 反向代理對外、SQLite 每日備份。做完發邀請碼給朋友就能連進來玩。

**Architecture:** 單一 Docker image（uvicorn 跑 FastAPI）。SQLite 檔在 bind mount。NPM 加一個 proxy host（子網域 → container）+ Let's Encrypt。備份 script 用 `sqlite3 .backup` + cron。

**J1900 現況**（見 `H:\Obsidian第二大腦\記憶\主機與連線.md`）：`ssh root@10.0.4.33` 免密碼、服務放 `/srv/`、容器用 `docker run` 手起、NPM 在 `/srv/npm` 管反代 + SSL、已有 DDNS `guantonj1900.duckdns.org`。

---

## 設計決策

1. **image**：多階段 Dockerfile，用 `python:3.12-slim` + `uv`。最終 image 只有 runtime 依賴。
2. **啟動**：`uvicorn server.app:create_app --factory --host 0.0.0.0 --port 8000`。
3. **資料**：`ROTXT_DB_PATH=/data/rotxt.db`，`-v /srv/rotxt/data:/data`。容器內非 root 使用者，`/data` 權限對好。
4. **設定**：`/srv/rotxt/rotxt.env`（`ROTXT_SERVER_HOST=0.0.0.0`、`ROTXT_TOKEN_TTL_HOURS=720`、`ROTXT_STAT_RESET_FREE=false`、`ROTXT_SKILL_RESET_FREE=false`——正式版洗點收費）。無外部 API 金鑰。
5. **對外**：NPM proxy host `rotxt.<某網域>` → `rotxt 容器:8000`，強制 HTTPS。子網域用哪個由使用者定（duckdns 的 `guantonj1900.duckdns.org` 走 path、或另開一個 A record）。
6. **備份**：`/srv/rotxt/backup.sh` 每天 04:30 `sqlite3 /srv/rotxt/data/rotxt.db ".backup /srv/rotxt/backups/rotxt-$(date +%F).db"`，保留 14 天。cron 或 systemd timer。
7. **更新流程**：本機 build → `docker save | ssh docker load`（J1900 無 registry）→ 換容器。runbook 寫清楚。
8. **正式硬化**（順便做）：
   - `@app.on_event("startup")` → lifespan（FastAPI 新式，deprecation 清掉）
   - 掛機 status 併發重複結算 → `_settle_current` 包 `connection.transaction()`，交易內重讀 `hunt_last_settled_at`，若已被別的請求更新過就跳過本次結算
9. **不做**：CORS（客戶端是 httpx 不是瀏覽器）、多 worker（SQLite 單檔 + friends-scale 用 1 worker）、CI/CD。

from contextlib import asynccontextmanager

@asynccontextmanager

## Task 4: 部署 runbook

**Files:** Create `docs/部署.md`

寫清楚每一步（給人照做，也給未來的自己）：

1. **首次部署**
   - 本機 `docker build -t rotxt:latest .`
   - `docker save rotxt:latest | gzip | ssh root@10.0.4.33 'gunzip | docker load'`
   - J1900：`mkdir -p /srv/rotxt/{data,backups}`
   - 上傳 `compose.yaml`（scp 到 `/srv/rotxt/`）、`rotxt.env`（照 example 填、`chmod 600`）、`backup.sh`（`chmod +x`）
   - `cd /srv/rotxt && docker compose up -d`
   - `curl -s localhost:8010/health`
   - 產首批邀請碼：`docker exec rotxt python -m server.admin invite --count 10`
   - NPM 管理介面（`http://10.0.4.33:81`）加 Proxy Host：域名 `rotxt.xxx`、Forward `127.0.0.1:8010`（或容器名，看 NPM 容器網路）、SSL 要新憑證、Force SSL、Websockets Support 開（未來 WebSocket 用）
   - 裝備份 timer：`cp deploy/rotxt-backup.* /etc/systemd/system/ && systemctl enable --now rotxt-backup.timer`（或加 crontab）
   - 朋友端：給 repo 或打包的 `client/` + `pyproject.toml`，`uv sync`，`uv run python -m client --server https://rotxt.xxx`

2. **更新版本**
   - 本機 build → save → ssh load
   - `cd /srv/rotxt && docker compose up -d`（會用新 image 重建容器）
   - `docker image prune -f`

3. **回滾**：`docker tag` 舊 image、`compose.yaml` 改回舊 tag、`up -d`

4. **改資料 / 熱修**：`data/*.json` 打進 image，改資料要重 build。**注意**：改 schema 目前是 `CREATE TABLE IF NOT EXISTS`——加欄位要手動 `ALTER TABLE` 或寫 migration（v1 開發期都砍 db 重建，正式上線後不能這樣）。

5. **常見問題**：
   - 容器起不來看 `docker logs rotxt`
   - `/data` 權限：容器內是 uid 1000，`chown -R 1000:1000 /srv/rotxt/data`
   - NPM 502：確認 `ports` 綁對、容器 healthy

6. **機密**：`rotxt.env` `chmod 600`、不進 git。邀請碼是唯一的「發放」機制——產了就記在 vault `帳號與服務.md`。
