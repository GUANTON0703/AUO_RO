## 設計決策

1. **商店**：v1 單一全域商店，不分城鎮。賣 `ItemDef.npc_buy is not None` 的道具 + `EquipmentDef.npc_buy is not None` 的裝備（買到的裝備 refine 0、無卡）。賣出價 = `npc_sell`（道具）或 `EquipmentDef.npc_sell`（裝備，refine/卡不加價，v1）。
2. **倉庫**：帳號層，3 隻角色共用。`account_items(account_id, item_id, qty)`、`account_equipment(id, account_id, equipment_id, refine, card_ids, acquired_at)`（沒有 equipped_slot——倉庫裡的不能穿）。deposit/withdraw 在「角色背包」與「帳號倉庫」間搬，走 `connection.transaction()` 原子。
3. **洗點**：`POST /api/characters/{id}/resetstats` → 所有屬性歸 1、花費 `base_level * 100` Zeny（`ROTXT_STAT_RESET_FREE=1` 時免費，開發預設免費）。`resetskills` → `learned_skills` 清空，花費 `job_level * 50` Zeny（同樣有免費開關）。
4. **起手裝**：建角色時發——`knife` ×1（未裝備）、`red_potion` ×10、`fly_wing` ×5。在 `POST /api/characters` handler 呼叫 `inventory.grant_starter_kit(char_id)`。
5. **背包/倉庫格數上限**：v1 不做（friends-scale，無濫用風險）。記進抽象清單待補。
6. **設定**：`server/config.py` 加 `stat_reset_free: bool = True`、`skill_reset_free: bool = True`。

## Task 1: NPC 商店

**Files:** Create `server/api/shop.py`; Modify `server/app.py`; Test `tests/test_api_shop.py`

端點（需 auth；買賣針對帳號的第一個角色，跟 hunt 一致）：
- `GET /api/shop` → `{items: [{id, name, price, kind}], equipment: [{id, name, price, slot}]}`（只列 npc_buy 有值的）
- `POST /api/shop/buy` body `{item_id, qty=1}` → 驗 `item_id` 可買、`qty>=1`、`zeny >= price*qty`；扣 Zeny、道具 `add_item` 或裝備 `add_equipment`（qty 次）
- `POST /api/shop/sell` body `{item_id, qty}` 或 `{equipment_instance_id}` → 道具：背包夠 → `consume_item` + Zeny += `npc_sell*qty`；裝備：實例存在且屬該角色且未裝備 → 刪除 + Zeny += `EquipmentDef.npc_sell`

    id           INTEGER PRIMARY KEY AUTOINCREMENT,
