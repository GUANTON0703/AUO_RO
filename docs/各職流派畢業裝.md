# 經典版仙境傳說 各職業主流流派與畢業裝

範圍：**pre-renewal / classic**（非復新 Renewal）。一轉 6 職 + 二轉 7 職，共 13 職，跳過新手。
目標裝定位：base 60~99 練功會想穿的「畢業向普通裝」，不含 MVP 卡神裝。
主要來源：iRO Wiki Classic（irowiki.org/classic）各職頁、Card Reference、Autocast、各武器分類頁；卡片數值用 pre-renewal。

用語：`[N]` = 帶 N 洞。武器旁的 Endow = 需要賢者附魔或元素轉換卷/屬性箭。
「共用」標記 → 見文末〈跨職共用清單〉。

## 劍士 Swordman（一轉）

一轉是過渡期，裝備幾乎全部帶進騎士 / 十字軍。建議直接照騎士方向配點（STR/VIT/DEX 或 STR/AGI）。

### Bash 劍士（主流練功）
一句話：衝 STR + DEX 用 Bash 單體秒殺，DEX 補命中、AGI 補攻速。配點 STR > DEX > VIT/AGI。

| 部位 | 選擇 | 備註 |
|------|------|------|
| 武器 | Blade[4] / Saber[3] / Ring Pommel Saber[3]；或 Two-Handed Sword 系（Katana[4]、Bastard Sword[3]） | 單手劍配盾較穩；帶洞塞種族/尺寸卡 |
| 副手/盾 | Guard[1] / Buckler[1] | 共用 |
| 鎧甲 | Adventurer's Suit[1] → Chain Mail[1] | 共用 |
| 披肩 | Muffler[1] | 共用 |
| 鞋 | Boots[1] / Shoes[1] | 共用 |
| 頭飾 | Cap[1] / Helm[1]（DEF）；或 Hot-Blooded Headband（STR+2） | |
| 飾品 ×2 | Clip[1] ×2 / Ring[1] ×2 | STR、SP |

### Magnum Break AoE 劍士
一句話：練火屬 AoE，配點同上但更吃 STR + 一點 INT 撐 SP。裝備同 Bash 劍士，武器優先高 ATK 雙手劍。

## 法師 Mage（一轉）

過渡期，裝備全帶進巫師 / 賢者。標準配點 INT 優先，DEX 次之。

### Bolt 法師（火/冰單發）
一句話：堆 INT 練 Fire Bolt / Cold Bolt 對點，DEX 縮咏唱。配點 INT 99 先、再 DEX。

| 部位 | 選擇 | 備註 |

一句話：靠垂直火牆卡怪安全清場，配點 INT/DEX，可摻少量 VIT。裝備同上。

一句話：衝 INT 撐 Heal / SP，VIT 抗性，準備轉牧師。配點 INT 高、VIT 起、DEX/LUK 少量。

| 部位 | 選擇 | 備註 |

## 騎士 Knight（二轉）

主流配點簡稱：SVD = STR/VIT/DEX，AGI = STR/AGI/VIT。STR 通常拉到 100~120。

### SVD Pierce 槍騎（單體 / MVP 向）
一句話：對大型怪用 Pierce（大型打 3 下）連刺，STR 爆傷、VIT 撐場、DEX 補命中與攻速。配點 STR 100+、VIT 80、DEX 45~60、少量 INT。

| 部位 | 選擇 | 備註 |
|------|------|------|
| 武器 | Pike[4]（MVP 用 +10「2:1:1」= 2 種族 1 屬性 1 尺寸）；一般練功用元素鍛造長槍（VVS 風/火 Lance）；Zephyrus（風、附 Thunderstorm） | 單手槍可配盾 |
| 副手/盾 | Shield[1] / Stone Buckler[1] + 對應種族減傷卡 | 共用 |
| 鎧甲 | Full Plate[1] / Chain Mail[1]；PvP 換元素卡甲 | 共用 |
| 披肩 | Manteau[1] + Raydric | 共用 |
| 鞋 | Boots[1] / Greaves[1] | 共用 |
| 頭飾 | Helm[1] / Bone Helm[1]（DEF）；練功可換 Hot-Blooded Headband | |
| 飾品 ×2 | Ring[1] + Mantis（STR+3）；或 Brooch[1] + Kobold（STR+1、CRIT+4） | 90+ 用有等級限制飾品 |

### AGI 雙手劍騎（Bowling Bash / Two-Hand Quicken）
一句話：Two-Hand Quicken 拉攻速、單手劍等級靠迴避，遇群怪切 Bowling Bash。配點 STR 90~100、AGI 80~99、DEX 40~60、VIT 10~30。

|------|------|------|
| 武器 | Katana[4]（BB 塞 4 尺寸/種族）/ Bastard Sword[3]；元素鍛造 Two-Handed Sword（VVS 風/火）；Veteran Sword[1]（BB/Bash +50%） | 雙手劍不可配盾 |
| 副手/盾 | 無（雙手劍） | 若用單手劍 + Knight Spirit 可配盾 |
| 鎧甲 | Chain Mail[1] / Silk Robe[1]（練功輕甲） | 共用 |
| 披肩 | Muffler[1] / Manteau[1] + Raydric 或 Bapho Jr.（AGI+3） | 共用 |

一句話：極高 VIT + 盾牌抗傷，靠聚怪 Brandish Spear / Bowling Bash 清場。配點 STR 80+、VIT 90~100、DEX 40。

## 獵人 Hunter（二轉）

三主流：DEX/AGI（DS 火力）、Falconer（鷹）、DEX/INT-VIT（陷阱 WoE）。

### DEX/AGI Double Strafe 獵人（單體 DPS 主流）
一句話：AGI 99 + DEX 拉到 140~150，DS 連射爆單體。配點 AGI 99 base、DEX 99 base（裝備堆到 150）、INT 9。

| 部位 | 選擇 | 備註 |
|------|------|------|
| 武器 | Composite Bow[4]（2 種族 + 2 屬性/尺寸，最泛用）；元素弓（Burning / Frozen / Earth / Gust Bow[1]）配對應箭 +25% | 換箭換屬性 |
| 副手/盾 | 無（弓為雙手；只有陷阱/鷹技可戴 Guard[1]） | |
| 鎧甲 | Tights[1]（DEX+1）；元素用 Coat[1] / Mantle[1] | 共用（弓職） |
| 披肩 | Muffler[1] + Raydric；MVP/練功用 + Dragon Tail（DS+5%、Flee+10、AGI+1）| |
| 鞋 | Boots[1] + Matyr / Firelock Soldier | 共用 |
| 頭飾 | Apple of Archer（DEX+3）/ 湊檔用 Binocular（DEX+1）；PvP 用 Feather Beret / Poo Hat | |

- **一轉（劍士/法師/弓手/服事/商人/盜賊）** iRO Wiki Classic 本身把 build 指向二轉頁，沒有獨立流派章節。上面的一轉流派是依「練該一轉時的實際打法 + 裝備會直接帶進二轉」整理的，配點方向以二轉主流回推。
- 卡片掉落怪只列最常見來源，部分怪（Hydra、Skeleton Worker、Raydric、Verit、Matyr 等）多地圖都有。
- Doppelganger（ASPD）、Phreeoni（HIT+100）等屬 MVP 卡，依需求未逐職列入畢業向清單。
- `Battle Axe[4]` 在 iRO Wiki Classic 鐵匠頁有列，但武器分類頁用 `Orcish Axe[4]`，兩者可能是同物不同譯名，本文以 `Orcish Axe[4]` 為準。
- Turtle General 卡 pre-renewal 效果數值（ATK+20%、3% 自動 Magnum Break Lv10）以常見伺服器實裝為準，官方 classic 敘述可能略有出入。
- 元素拳刃「Katar of Raging Blaze / Frozen Icicle / Piercing Wind / Quaking」slot 為 0 或 3（依掉落），要帶洞版才能鑲卡。
