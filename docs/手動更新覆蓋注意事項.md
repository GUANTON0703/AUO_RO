# 手動下載 GitHub 更新、覆蓋舊資料夾的注意事項

一般情況請直接跑 `更新功能.bat`（中文）或 `update.bat`（英文，主控台會亂碼時用這支）。
下面這份只在 Git 壞掉、無法 `git pull` 時，才需要手動下載 zip 覆蓋。

## 一句話

下載 zip 後，把裡面的檔案「合併覆蓋」到現有資料夾就好。
**不要先把舊資料夾整個刪掉再貼新的**，那樣會清掉你的存檔。

## 更新前

1. 關掉 ROtxt 伺服器（`start_server.bat` 的視窗關掉）。
2. 手動備份這幾個檔到資料夾外面，例如複製到桌面：
   - `rotxt.db`、`rotxt.db-wal`、`rotxt.db-shm` — 玩家存檔與進度
   - `.env` — 連線位置、邀請碼等設定
   - 如果你的 `.env` 有設 `ROTXT_DB_PATH`，資料庫在那個路徑，不是 `rotxt.db`，備份那個

## 覆蓋時

3. 到 GitHub 專案頁，`Code` → `Download ZIP`，解壓縮。
4. 把解出來的檔案全選，貼到現有 ROtxt 資料夾，選「取代目標中的檔案」。
5. zip 裡本來就不含 `rotxt.db`、`.env`、`.venv/`、`backups/`，所以合併覆蓋不會動到它們。前提是你沒有先刪舊資料夾。

## 覆蓋後

6. 這次更新如果有「刪掉某些舊程式檔」，手動覆蓋不會幫你刪，舊檔會留著變孤兒檔，有機會讓程式出錯。
   - 有懷疑就比對一下，或乾脆用 `update.bat` 重跑一次（Git 修好之後）。
7. 開一個命令列到 ROtxt 資料夾，跑 `uv sync` 更新套件。沒裝 uv 就先裝。
8. 重開 `start_server.bat`。伺服器啟動時會自己跑資料庫 migration，把 `rotxt.db` 的結構補到新版。只要你沒動到 `rotxt.db`，這步不用管。

## 檢查有沒有出事

9. 伺服器有正常起來、瀏覽器進得去、舊角色還在、背包沒少東西，就成功了。
10. 如果角色不見或報錯，把第 2 步備份的 `rotxt.db` 三個檔貼回去，覆蓋現有的，再重開伺服器。

## 絕對不要碰

- `rotxt.db` / `rotxt.db-wal` / `rotxt.db-shm`：玩家存檔
- `.env`：機密設定，zip 裡沒有，弄丟要重寫
- `.venv/`：Python 環境，砍掉要重跑 `uv sync`
- `backups/`：`更新功能.bat` 產生的自動備份
